# Car-Manager-Mobile-App
CarManager is a cross-platform mobile application developed with .NET MAUI, designed to serve as a comprehensive digital logbook for vehicle owners. The application allows users to easily manage multiple vehicles, track fuel fill-ups, and automatically calculate average fuel consumption. Furthermore, it keeps a detailed history of maintenance services and helps drivers monitor recurring expenses such as insurance, vignettes, and annual technical inspections. Built with a clean MVVM architecture, the app ensures fast performance and data privacy by storing all information locally on the device using SQLite.
